# Графовые нейросети для анализа связей участников финансового расследования

Проект по дисциплине «Интеллектуальные системы управления и обработки информации в сфере финансовой безопасности и компьютерной криминалистике».

Цель работы — построить граф переводов между участниками (компании, ИП, люди) и проверить, лучше ли графовая нейросеть находит причастных к отмыванию денег, чем модель, которая видит только признаки самого участника.

## Данные

[IBM Transactions for Anti Money Laundering](https://www.kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml), вариант HI-Small: синтетические переводы с меткой отмывания, лицензия CDLA-Sharing-1.0. В репозиторий данные не входят, их скачивает `download_data.py` (около 510 МБ).

## Как запустить

```bash
pip install -r requirements.txt
```

```bash
python download_data.py
```

```bash
jupyter lab participants_gnn.ipynb
```

Работа выполнена на Python 3.13 с видеокартой NVIDIA RTX 3070 Laptop, полный расчёт ноутбука занимает около 6 минут. Промежуточные результаты сохраняются в `results/`, и при повторном запуске уже посчитанное не пересчитывается.

## Результаты

Участник считается причастным, если отправил или получил хотя бы одну отмывочную транзакцию: таких 5 082 из 166 207 (3,06%). Метрики на тестовой выборке, среднее по трём seed:

| Модель | AP | ROC-AUC | F1 |
|---|---|---|---|
| Градиентный бустинг, без графа | 0,255 | 0,843 | 0,286 |
| Та же нейросеть, без графа | 0,243 | 0,819 | 0,272 |
| GraphSAGE, граф участников | 0,339 | 0,861 | 0,360 |

Нейросеть без рёбер работает на уровне бустинга, а с рёбрами AP растёт примерно на 0,1. Ещё в ноутбуке:

- сравнение 1, 2 и 3 слоёв GraphSAGE (AP 0,315, 0,339 и 0,350)
- разбор по типам схем отмывания: граф сильнее всего помогает на FAN-OUT, GATHER-SCATTER и SCATTER-GATHER
- пример участника, которого нашёл только GraphSAGE
